# Tenant logo SVG — AI prompt kit

Use this folder when asking any model to generate or rewrite a **tenant brand mark** for Rolvix (`logoSvg`).

| File | Purpose |
|------|---------|
| [`PROMPT.md`](./PROMPT.md) | Copy-paste system/user prompt for the model |
| [`examples/tennis-club.svg`](./examples/tennis-club.svg) | Reference mark (court + racket) already in platform format |

Paste `PROMPT.md` into the chat, then add: company name, industry, primary/accent hex, and optional mood notes.
